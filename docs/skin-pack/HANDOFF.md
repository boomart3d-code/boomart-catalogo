# Regla comercial corregida: base obligatoria y adicionales al pack

04/11/2026, Codex. Adrián corrigió el contexto: no se venden skins sueltas a S/20. Cada compra parte de una base + una skin por S/50; cada temática adicional al mismo pack suma S/20. Confirmó expresamente mantener base + los 11 diseños distintos por S/200.

Reglas vigentes: base + 1 skin = S/50; base + 2 = S/70; base + 3 = S/90; base + colección completa = S/200. El configurador tiene dos modos (pack configurable y colección). Dentro del pack se elige primero la skin incluida y después se marcan temáticas adicionales. No hay modo «Solo skin». El total cambia con la selección; las miniaturas identifican incluida/adicionales y las etiquetas permiten quitar extras. Once diseños distintos activan automáticamente la colección de S/200.

El carrito añade el pack en una operación con importes derivados del catálogo. Internamente conserva una línea de base + skin y las adicionales de S/20; no acepta adicionales si no hay un pack con base. Retirar la última base elimina las adicionales huérfanas. Los carritos antiguos huérfanos se depuran antes de reutilizarlos, sin convertir una skin en una compra de S/50 silenciosamente. Los enlaces antiguos de una skin adicional abren el pack con esa temática incluida y muestran S/50 antes de agregar. Compartir y WhatsApp incluyen la configuración completa; los enlaces conservan modelo y parámetro skins.

No cambian los precios acordados ni las otras familias de productos. Se actualizan descripción, aviso, detalle y etiquetas internas de adicionales en products.json, sus derivados y el rango de ofertas del configurador. Los adicionales son componentes condicionados a base, no ofertas independientes. Versiones: cart.js v13, checkout.js v35, app.js v72 y product-skins.js/css v2. Se mantiene la revisión humana de pedidos por validar; no se tocó la BD ni se generaron pedidos/clientes reales.

Pruebas locales: 132 reglas de base/diseños/cantidad, más casos de duplicados, entradas inválidas, cantidad por pack, carritos antiguos y retirada de base. 113 recorridos UI para 320/390/1280 px, modal y ficha individual, imágenes, enlaces, zoom y totales 50/70/90/200; incluye compra local aislada y enlace antiguo. 970 verificaciones generales de precios/catálogo/feeds/carrito/cupón; checkout 6/6. La prueba antigua de precios confundía el precio por signo de Pandora con su set inicial: se confirmó el mismo resultado anterior (400 para 2 sets), y se corrigió la expectativa del test sin alterar ese producto. Contraste: 3246 textos, 104 fichas móvil/escritorio, mínimo 4.84:1. Acciones 248 casos; desbordes 104 páginas × 320/390, cero fallos.
