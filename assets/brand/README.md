# Isotipo oficial BoomArt · BA

Fuente oficial entregada por Adrián el 14/10/2026. No redibujar ni reinterpretar.

- `boomart-icon-original-light.png`: original para fondo claro.
- `boomart-icon-original-dark.png`: original para fondo oscuro.
- `boomart-icon-transparent-light.png`: PNG transparente negro/rojo.
- `boomart-icon-transparent-dark.png`: PNG transparente blanco/rojo.
- `boomart-icon-transparent.png`: alias transparente principal para fondos claros.
- `boomart-icon-light.svg`: vector transparente para fondo claro.
- `boomart-icon-dark.svg`: vector transparente para fondo oscuro.
- `boomart-icon.svg`: alias vectorial principal para fondos claros.
- `boomart-icon-light-background.png`: PNG cuadrado con fondo blanco.
- `boomart-icon-dark-background.png`: PNG cuadrado con fondo negro.
- `boomart-icon-1024.png`: máster PNG cuadrado para exportaciones.

`../boomart-mark.svg` elige automáticamente la variante clara u oscura según
el tema del navegador. Los PNG 16/32/48/180/192/512/1024 y `../favicon.ico`
son exportaciones sin deformación del mismo isotipo.
