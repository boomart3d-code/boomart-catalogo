# Isotipo oficial BoomArt · BA

Fuente oficial entregada por Adrián el 14/10/2026. No redibujar ni reinterpretar.

## Significado oficial

- **B** de **Boom**.
- **A** de **Art**.
- La bomba y su mecha representan la onomatopeya de una explosión:
  **«¡Booom!»**. El concepto expresa **arte explosivo**, creatividad con
  impacto y la personalidad visual de BoomArt.

Toda aplicación debe seguir también `../../docs/IDENTIDAD_VISUAL_BOOMART.md` y
mantener la identidad de la web: blanco, negro, rojo BoomArt, tipografía fuerte,
retícula precisa y producto real como protagonista.

- `boomart-icon-original-light.png`: original para fondo claro.
- `boomart-icon-original-dark.png`: original para fondo oscuro.
- `boomart-icon-transparent-light.png`: PNG transparente negro/rojo.
- `boomart-icon-transparent-dark.png`: PNG transparente blanco/rojo.
- `boomart-icon-transparent.png`: alias transparente principal para fondos claros.
- `boomart-icon-light.svg`: vector transparente para fondo claro.
- `boomart-icon-dark.svg`: vector transparente para fondo oscuro.
- `boomart-icon.svg`: alias vectorial principal para fondos claros.
- `boomart-icon-light-background.png`: PNG cuadrado con fondo blanco.
- `boomart-icon-dark-background.png`: PNG cuadrado con fondo negro.
- `boomart-icon-1024.png`: máster PNG cuadrado para exportaciones.
- `boomart-favicon-transparente-4096.png`: PNG maestro transparente negro/rojo.
- `boomart-favicon-claro-para-fondo-oscuro-4096.png`: PNG maestro transparente blanco/rojo.

`../boomart-mark.svg` y `boomart-favicon-universal.svg` usan una placa blanca
oficial con esquinas redondeadas (radio aproximado del 16 %), bomba negra y A
roja. Esta versión autocontenida se utiliza en la
pestaña porque el navegador no permite detectar de forma fiable si cada pestaña
activa tiene fondo blanco o negro. Los PNG 16/32/48/180/192/512/1024 y
`../favicon.ico` son exportaciones sin deformación del mismo isotipo.
