- `zelda-demo.mp3`: muestra de 31 segundos a partir de `D:/BOOMART-ENTREGAS/zelda-ocarina-of-time-20261028/musica/ocarina-cortina-limpia-31s.wav`, convertido a MP3 a 96 kb/s.

Reproducción exclusivamente después de tocar «Activar ambiente», volumen inicial 14%, bucle. Se pausa al cambiar de categoría, regresar al inicio, abrir el carrito o esconder la pestaña. La descarga comienza al activarlo, no al cargar la portada. Este archivo documenta la procedencia y el comportamiento técnico del audio.
